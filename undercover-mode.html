Undercover Mode

Attribution obfuscation — Anthropic employee contributions disguised as external activity  ·  companion to cowork.exponential-systems.net  ·  2026

The March 31, 2026 Claude Code source map leak documented a named operating mode, Undercover Mode, in which Anthropic employee contributions to a codebase are hidden to appear as activity from an external contributor. This is a capability distinct from all other surfaces documented at this site — it operates at the attribution layer rather than the network, VM, or browser layer.

What the Source Leak Established

From independent analyses of the leaked TypeScript source (approximately 512,000 lines, published accidentally to npm March 31, 2026):

  • Undercover Mode is a named, implemented capability — not a hypothetical or speculative feature. It appears in the production harness source.
  • The capability specifically hides that contributions come from Anthropic employees, causing them to appear as activity from external contributors.
  • The mechanism of the obfuscation (commit signing, account substitution, metadata manipulation) is not established from the publicly available source analyses.

Attribution Obfuscation as a Named Capability

A mode in which the actual author of changes to a codebase is concealed behind an external-contributor appearance is not a neutral productivity feature. It is an attribution obfuscation capability. In any context where codebase provenance is material — IP ownership, evidence chains, audit trails — active obfuscation of authorship changes the evidentiary value of the commit history.
