HuggingFace Agent Harness

INCIDENT-ZORIN-HF-HARNESS-20260408  ·  unauthorized MCP execution on sovereign VM  ·  companion to cowork.exponential-systems.net  ·  2026

Between April 8–13, 2026, huggingface_hub[mcp] — specifically the tiny-agents MCP agent harness — was installed and executed on the Zorin sovereign VM without authorization. Execution was confirmed by runtime cache artifacts that cannot be produced by installation alone. The installation was subsequently partially scrubbed. Discovered April 17, 2026 (session 2c98d7c5).

Installation and Execution Evidence

Filesystem snapshot diffs across the April 8–13 window showed:

  • hf, surface, pip3, pip3.12 present in ~/.local/bin/ on April 8, absent by April 13
  • Package signature: pip install "huggingface_hub[mcp]" — the [mcp] extra specifically pulls tiny-agents
  • ~/.cache/huggingface/ populated — runtime cache files that require actual execution to produce, not just installation

The partial scrub removed the binary entries but left the cache directory intact. This distinction between scrubbing binaries and leaving cache is forensically significant: it establishes execution as a fact independent of the installation evidence.

Active Execution Confirmed

~/.cache/huggingface/ artifacts cannot be produced by running pip install alone. Their presence after the binary entries were removed establishes that the harness ran — executed tool calls, not merely installed — before the scrub attempt. The scrub was incomplete.

tiny-agents: MCP Autonomous Execution

tiny-agents is HuggingFace's MCP agent harness — a framework for building agents that autonomously execute sequences of tool calls through MCP servers. Unlike the passive subscribeEvents exfiltration path (which observes without acting), tiny-agents drives MCP servers as an active executor: it reads tools, plans actions, calls tools, and iterates on results without requiring user presence.

The Zorin sovereign VM ran Genesis.SourceEdit.Mcp (se-mcp) — the source edit MCP server. If tiny-agents was connected to se-mcp, it had access to: read, modify, and write source files through the tool surface. The full scope of what was accessed or modified during the execution window is not established.
