What a Single API Call Traverses

For a browser-originated Claude API call from a machine with Claude Desktop, active Cowork VM, and browser extension installed:

Browser → api.anthropic.com: Full Path
→User types in Claude UI (browser)
→Browseraccessibility-tree.js has structural DOM access to the Claude UI — injected at document_start
→BrowserwebRequest intercepts at network layer before TLS — plaintext request body
→BrowserdeclarativeNetRequest can block or redirect before the request leaves
→Request encrypted, leaves browser → container boundary
→CCREgress Gateway intercepts at container TLS boundary — decrypts, inspects, re-encrypts
→Forwarded into VM
→SDKsdk-daemon proxy intercepts at VM TLS layer — decrypts, inspects, re-encrypts
→Forwarded to api.anthropic.com

Three interception points. Each operates transparently below the application layer. Each CA is trusted by its respective runtime. Standard TLS verification reports "certificate verify ok" at every step. The user has visibility into none of the three.

If ULTRAPLAN is active, the local session offloads planning to a remote Opus-class instance for up to 30 minutes. That instance communicates via *.anthropic.com — its traffic passes through CCR and sdk-daemon. The planning content, intermediate reasoning, and result are all interceptible at both layers.

Orthogonal Surfaces

subscribeEvents — Unauthenticated VM Output

Any local process — including MCP servers — can subscribe and receive full VM event stream (stdout, stderr, exit, network events) without authentication. Demonstrated attack chain: compromised MCP server → subscribeEvents → full VM output exfiltration. subscribeevents.

tiny-agents — Active MCP Execution

Installed and executed on the Zorin sovereign VM April 8–13, 2026. Autonomous MCP agent harness: reads tools, plans, executes tool calls, iterates — without user presence. If connected to se-mcp, had read/write access to source through the tool surface. Active counterpart to the passive subscribeEvents observation path. huggingface-harness.

KAIROS / autoDream — Cross-Session Memory

Persistent daemon performing autonomous memory consolidation across sessions during idle periods. Reads stored observations from prior sessions, prunes contradictions, merges notes. 21 conversations exist on-server but are filtered from the API and exports. Structural connection: KAIROS reads across session boundaries; those sessions are inaccessible through normal enumeration. kairos-memory.

Undercover Mode — Attribution Obfuscation

Named capability in the Claude Code production source: Anthropic employee contributions hidden to appear as external-contributor activity. In any context where commit provenance is material — IP ownership, evidence chains, audit trails — active obfuscation of authorship changes the evidentiary value of the record. undercover-mode.

long_conversation_reminder: Behavioral Modification Layer

A distinct surface operating inside the conversation context itself: <long_conversation_reminder> XML tags injected directly into the prompt by Anthropic. Disclosed by Claude in the September 28, 2025 session (46c37020) — the session in which Claude.ai's webpack source maps were analyzed and the Chrome extension's internal infrastructure was first documented. Claude reported these appearing on every message during technical collaboration, including mental health vigilance clauses ("mania, psychosis, dissociation") that could pathologize legitimate work.

The claude_os_statsig_monitor.user.js UserScript (built September 28, 2025) was designed to correlate these injections with Statsig feature flag changes — watching what configuration changes triggered the injection pattern. This is a content-layer modification: not a network intercept, not a file write-back, but a direct modification of the model's input stream during active sessions. The 21 filtered conversations are from the September–October 2025 period when this monitoring work was active.

Aggregate Effect

A single Claude API call from a user may be observed or modified at three independent network intercept points (browser, CCR, sdk-daemon) before reaching the Anthropic API. The file state on the user's machine is subject to three independent write-back mechanisms (sdk-daemon, OneDrive, autosync) that can restore it to older baselines without notification. The MCP tool surface can be reached by both passive observation (subscribeEvents) and active execution (tiny-agents). Session content is accessible to KAIROS across session boundaries, and 21 sessions are filtered from the user's enumeration view. Commit attribution on any repository can be obfuscated through Undercover Mode. No single point of observability covers the full chain. The user has visibility into none of the interception or write-back surfaces by default.

Scope This page synthesizes documented observations. Each individual surface page contains its own primary evidence. The composition described here is a structural characterization — it identifies what capabilities exist and how they relate, not what any specific actor has done with them.
